# BlueKiwi desktop downloads

Download the BlueKiwi desktop app from [Releases](https://github.com/bluekiwiai/bluekiwi-desktop/releases). This repository contains installers and download information; application source is maintained separately.

## Windows preview

Open the [Windows preview release](https://github.com/bluekiwiai/bluekiwi-desktop/releases/tag/v0.1.0-windows-preview.1) and download the installer matching your PC:

- **x64:** most Windows PCs with Intel or AMD processors.
- **ARM64:** Windows PCs with ARM processors, such as Snapdragon.

Run the installer, open BlueKiwi, and sign in with your BlueKiwi account. The app connects to [app.bluekiwi.ai](https://app.bluekiwi.ai) and requires an internet connection.

This preview is unsigned, so Windows may show an unknown-publisher or reputation warning. It is intended for testing. The x64 installer is checked on a Windows runner; installation on a physical ARM64 PC remains a tester check.

## Updates

The desktop app includes background update checks and a restart prompt after an update downloads. Automatic delivery requires a configured release feed and signing; that release setup is not active for this preview. Until it is enabled, download new preview installers from this repository. Hosted BlueKiwi interface changes appear without reinstalling the desktop app.

## macOS

The macOS app already exists; a public signed Mac download will be added separately.
